# Security Policy

This SDK is a client for a payment platform. If you believe you have found a security
vulnerability in this repository (not in the Treps API/platform itself), please report it
responsibly.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email **[REPLACE ME: security contact email]** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal code sample is ideal)
- The SDK version affected

We aim to acknowledge reports within 3 business days and will keep you updated as we
investigate and remediate.

## Scope

This policy covers the `treps-sdk` package itself (dependencies, packaging, published code).
Vulnerabilities in the Treps Payment Orchestration API or platform should be reported through
your regular account/merchant support channel instead.

## Supported Versions

Only the latest published major version of this SDK receives security fixes.
